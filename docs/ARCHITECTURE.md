# Архитектура

## Выбор реализаций

| Подсистема | Основа | Что изменено |
|---|---|---|
| Очереди, импорт, расписание | Bluesky Queue Poster | Единая SQLite-схема, транзакции, фиксированный record key, восстановление и независимый worker каждого аккаунта |
| Лайки и фолловинг | Bluesky Automation Tool | История разделена по аккаунтам, добавлены проверки viewer, пауза/стоп и общий API-клиент |
| Экспорт | Улучшенная ветка Queue Poster + Posts Exporter | Один конвейер фильтрации, диапазон дат, ответы, AI-файлы и общий формат очереди |
| Аккаунты и секреты | Новая общая реализация | Один каталог профилей, Windows DPAPI вместо открытых паролей в JSON |
| GUI и журнал | Новая общая оболочка | Семь разделов, общий статус, трей, rotating log и единые фоновые callback-события |

## Слои

- `app/database.py` — транзакционная SQLite-модель состояния.
- `app/security.py` — защита и чтение App Password.
- `app/bluesky.py` — единственная граница Bluesky API для всех функций.
- `app/scheduler.py` — независимые долгоживущие очереди аккаунтов.
- `app/automation.py` — останавливаемые сессии лайков и фолловинга.
- `app/importer.py` и `app/exporter.py` — чистые конвейеры TXT.
- `app/ui/` — CustomTkinter, только координация и отображение состояния.

Потоки не изменяют Tk-виджеты напрямую: результат отправляется в главный цикл через `after`. SQLite-соединение открывается на операцию, запись сериализована `RLock` + `BEGIN IMMEDIATE`.

## Состояние очереди

Запись создаётся в `queue` с hash текста, позицией и неизменным `record_key`. Успешная публикация и удаление из очереди выполняются в одной локальной транзакции с переносом в `post_history`. Ошибка меняет только счётчик попыток и расписание. Поэтому текст не удаляется до подтверждённого ответа или успешной проверки существующей AT Protocol записи.

Перенос в историю и запись следующего времени публикации также атомарны. Повторяемые сетевые, серверные и rate-limit ошибки используют backoff; неповторяемая ошибка оставляет запись на месте и переводит очередь на паузу для ручного решения.
