## Agnia Bluesky Suite 1.3.2

### Исправлено
- **Завершение работы из системного трея:** устранена ошибка `can't invoke "tk_messageBox" command: application has been destroyed` при выборе «Выход» в меню трея.
- **Очистка и отмена фоновых таймеров интерфейса:** корректно отменяются циклические таймеры `_pump_ui` и `_tick_job` перед закрытием главного окна.
- **Безопасная обработка исключений интерфейса:** метод `report_callback_exception` больше не пытается отображать модальное окно с ошибкой после уничтожения графического интерфейса или в процессе закрытия программы.
- **Разделение фазы запуска и завершения:** ошибки выхода из главного цикла больше не маскируются под ошибку запуска приложения.

### Обновление
Полностью завершите предыдущую версию через меню трея, замените EXE в рабочей папке (`AgniaBlueskySuite.exe`). Все данные аккаунтов, пароли, черновики и история сохраняются.
