# Аудит и проверка 1.3.2

Устранение сбоя при завершении программы через системный трей.

## Причина проблемы
При выборе «Выход» в меню трея вызывался метод `_finish_quit()`, который вызывал `destroy()` окна Tkinter. Однако периодический таймер опроса очереди коллбэков `_pump_ui` (вызываемый каждые 50 мс) не был отменён. При срабатывании таймера вызов `self.winfo_exists()` бросал исключение Tcl `application has been destroyed`. Перехватчик ошибок Tkinter `report_callback_exception` пытался вызвать `messagebox.showerror` на уничтоженном окне, вызывая повторный TclError. В результате `main.py` перехватывал исключение из `mainloop()` и отображал диалог «Программа не смогла запуститься».

## Исправления в 1.3.2

| Область | Исправление | Описание |
|---|---|---|
| `MainWindow` | Отмена `_pump_job` | Хранение ID таймера `_pump_job` и его явная отмена в `_finish_quit` |
| `MainWindow` | Защита `_pump_ui` | Проверка `_quitting` и безопасный перехват `winfo_exists` |
| `MainWindow` | Защита `report_callback_exception` | Пропуск показа диалоговых окон, если программа закрывается (`_quitting`) или виджет уничтожен |
| `MainWindow` | `self.quit()` перед `destroy()` | Корректная остановка главного цикла Tk перед уничтожением дескрипторов |
| `common.py` | Защита `drain_ui_callbacks` | Безопасная проверка существования виджета перед вызовом коллбэка |
| `main.py` | Разделение фаз запуска и работы | Исключения завершения работы не вызывают диалог «Программа не смогла запуститься» |
