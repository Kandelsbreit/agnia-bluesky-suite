## Agnia Bluesky Suite 1.3.0

### Новое
- Редактор очереди: текст, вложения, поиск, массовое выделение, восстановление пропущенных записей.
- Календарь по всем аккаунтам и точная дата публикации.
- Черновики по аккаунтам, изображения с alt-текстом, MP4-видео, карточки ссылок, предпросмотр и упоминания.
- Автоматические резервные копии; защищённые паролем архивы с аккаунтами, очередью, черновиками и вложениями; восстановление при перезапуске.
- Общие сессии аккаунта, защита от второго запуска и завершение фоновых задач без блокировки интерфейса.

### Исправлено
- Чужие репосты больше не считаются собственными публикациями при сверке.
- Ошибка отправки относится к исходной записи; перестановка очереди не может удалить соседнюю.
- Ошибочные посты остаются видны; пропущенные можно повторно поставить в очередь.
- Ручная отправка сохраняется до запроса и восстанавливается с прежним ключом.
- Экспорт прошлых периодов не завершается на странице новых записей; отмена не перезаписывает полный архив.
- Ошибка сохранения ключа не приводит к невосстановимым паролям; потерянный ключ не подменяется новым.
- Паузы сохраняются после перезапуска; исчерпанная лента завершает цикл лайкинга.
- Обновлены README, описание хранения паролей и фактических ограничений.

### Обновление
Полностью завершите предыдущую версию через трей, замените EXE в прежней папке, сохраните папку `data`. Перед переходом схемы создаётся резервная копия. Для переноса между компьютерами используйте защищённый архив из настроек.

Локальные автоматические ZIP-копии включают ключ аккаунтов. Для передачи используйте архив с паролем. Календарь публикует только при запущенном приложении; экспорт удалённых постов пока текстовый. Реальные публикации не выполнялись в автоматических проверках.
