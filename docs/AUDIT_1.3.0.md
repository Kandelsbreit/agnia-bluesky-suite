# Аудит и проверка 1.3.0

Исходная версия: commit `1149675f9e43395adb7fe219f90eb98cbc5612cf` (1.2.4). Проверены база и миграции, очередь, ручная публикация, API, авторизация, секреты, импорт/экспорт, автоматизация, GUI, завершение, перенос данных и выпускной workflow.

## Проверки

- Набор unit/regression tests: база, импорт, экспорт, API, очередь, автоматика, криптография, backup/restore, медиа, даты, блокировка запуска.
- `ruff check`, `compileall`.
- `tests/gui_smoke.py`: создание настоящих Tk-окон, все семь разделов, черновики по аккаунтам, предпросмотр медиа, редактор очереди, поиск на кириллице, пропуск, история, календарь и настройки. Используются тестовые аккаунты без паролей; сетевых публикаций нет.
- GitHub Actions: Linux GUI-тест со скриншотами; затем Windows-тесты, PyInstaller one-file EXE, запуск `--smoke-test`, ZIP и SHA-256. Публикация релиза из main выполняется только после успешных зависимых проверок.

## Границы проверки и оставшиеся ограничения

Ни один тест не публикует в реальные аккаунты пользователя. Фактическая доставка изображений/видео, серверные ограничения конкретного аккаунта, обновление настоящей сессии и системный трей Windows требуют проверки в реальном окружении. Windows packaged smoke проверяет импорты GUI и зависимости, базу и ресурсы, но не открывает интерактивный desktop на runner.

Сверка последних 100 записей не является полной синхронизацией всей истории. Одновременно работающие копии на двух компьютерах не имеют распределённой блокировки. Локальная блокировка действует для одной папки данных. EXE не подписан коммерческим сертификатом. Экспорт удалённых постов остаётся текстовым. Видеопредпросмотр показывает имя и описание; воспроизведение видео внутри приложения не реализовано. Уничтожение диска не компенсируется копиями, хранящимися на нём же.
